# 자취방 지도 (jachi-map)

경희대학교 서울캠퍼스 주변(회기동·이문동·휘경동)의 **전월세 실거래가**를 지도에 보여 주는 웹앱입니다.
학생이 예산·통학 시간·편의시설을 기준으로 자취방을 비교할 수 있게 만드는 것이 목표입니다.

- 프레임워크 없이 **Vite + 순수 JavaScript** 로 만들었습니다. 설치하는 패키지는 `vite` 하나뿐입니다.
- 서버나 데이터베이스가 없습니다. 공공 API 자료를 **스크립트로 미리 받아 `public/*.json` 파일로 저장**하고, 화면은 그 파일을 읽습니다.

---

## 1. 빠르게 실행해 보기

준비물: **Node.js 24 권장** (개발·확인한 버전. 데이터 스크립트가 `node --env-file-if-exists` 옵션을 쓰므로 너무 오래된 Node 에서는 실패합니다)

```bash
npm install
cp .env.example .env      # 그다음 .env 에 키를 넣는다 (아래 2장)
npm run dev               # http://localhost:5174 에서 열림
```

- 저장소에 **이미 받아 둔 데이터(`public/*.json`)가 들어 있어서**, 키가 없어도 화면과 기능은 동작합니다.
- 다만 `VITE_KAKAO_JS_KEY` 가 없으면 카카오맵 대신 **OpenStreetMap 임시 지도**로 뜨고, 로드뷰 버튼이 숨겨집니다.
- 포트는 5174 로 고정되어 있습니다. 카카오 앱에 등록한 도메인과 맞아야 하기 때문입니다.

## 2. API 키 (`.env`)

`.env` 는 git 에 올라가지 않습니다. **키는 인계받는 사람이 직접 발급**해야 합니다.

| 변수 | 어디서 | 용도 | 없으면 |
|---|---|---|---|
| `VITE_KAKAO_JS_KEY` | 카카오 개발자 > 내 애플리케이션 > 앱 키 > JavaScript 키 | 화면의 카카오맵·로드뷰 | 임시 지도(OSM)로 대체 |
| `KAKAO_REST_KEY` | 같은 앱의 REST API 키 | 주소→좌표, 편의시설 검색 (스크립트) | `fetch-deals`, `fetch-amenities` 실행 불가 |
| `DATA_GO_KR_KEY` | 공공데이터포털 마이페이지의 일반 인증키 | 실거래가, LH 공고 (스크립트) | `fetch-deals`, `fetch-lh` 실행 불가 |

### 카카오 앱 설정 (빠뜨리기 쉬움)
1. **제품 설정 > 카카오맵** 사용 설정을 **ON** — 안 켜면 키가 맞아도 `disabled OPEN_MAP_AND_LOCAL service` 로 거절됩니다.
2. JavaScript 키의 **JavaScript SDK 도메인**(옛 화면: 플랫폼 > Web)에 `http://localhost:5174` 등록 — 안 하면 `domain mismatched` 로 거절됩니다. 배포하면 배포 주소도 추가해야 합니다.

### 공공데이터포털 활용신청 (모두 자동승인, 같은 인증키 사용)
- 국토교통부_연립다세대 전월세 실거래가 자료
- 국토교통부_오피스텔 전월세 실거래가 자료
- 한국토지주택공사_분양임대공고문 조회 서비스
- (아직 안 씀) 국토교통부_단독/다가구 전월세 실거래가 자료

승인 직후에는 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` 가 날 수 있습니다. 보통 한두 시간 뒤 풀립니다.

## 3. 데이터 갱신

화면이 읽는 파일은 모두 `public/` 에 있고, 아래 스크립트로 다시 만듭니다. **순서가 중요합니다** (뒤 단계가 앞 단계 결과를 읽음).

```bash
npm run fetch-deals          # 1) 실거래가 → public/deals.json            (DATA_GO_KR_KEY, KAKAO_REST_KEY)
npm run fetch-amenities      # 2) 편의시설 → public/amenities.json        (KAKAO_REST_KEY)
npm run fetch-travel-times   # 3) 건물→목적지 도보·자전거 → public/travel-times.json   (키 불필요, 약 1분)
npm run fetch-amenity-walk   # 4) 건물→편의시설 도보거리 → public/amenity-walk.json   (키 불필요, 약 3~4분)
npm run fetch-lh             # 5) LH 임대공고 → public/lh-notices.json     (DATA_GO_KR_KEY) — 다른 단계와 독립
```

- 실거래가(1)를 새로 받았으면 **3·4 도 반드시 다시** 돌려야 합니다. 건물 id 가 바뀌면 소요시간이 비어 보입니다.
- 목적지(`src/destinations.js`)를 바꿨으면 3 을 다시 돌립니다.
- 3·4 는 공개 경로 서버(`routing.openstreetmap.de`)를 씁니다. 요청이 몰리면 **429(거절)나 연결 거부**가 나고 한동안 막힙니다. 스크립트에는 간격·재시도가 들어 있지만, 그래도 실패하면 몇십 분 뒤 다시 실행하세요.
- 주소→좌표 결과는 `data/geocode-cache.json` 에 캐시됩니다(git 제외). 지워도 다시 만들어집니다.

## 4. 폴더 구조

```
index.html              화면 뼈대 (왼쪽 패널 + 지도 + 로드뷰 덮개)
src/
  main.js               화면 로직 전부: 상태(state), 필터, 목록, 상세 패널, 마커, 경로, 편의시설, LH, 로드뷰
  map.js                지도 담당. 카카오맵 / Leaflet(OSM) 둘 중 하나를 같은 함수 모양으로 감싼다
  routing.js            도보·자전거 경로와 소요시간(OSRM 공개 서버), 오르막·내리막(Open-Meteo 고도 API)
  destinations.js       통학 목적지 28곳 (경희대 건물·역) 좌표
  sampleData.js         예시(가짜) 건물 데이터. public/deals.json 이 없을 때만 쓰임
  style.css             스타일
scripts/                데이터 받아 오는 Node 스크립트 (3장)
public/                 화면이 읽는 데이터 파일 (스크립트 결과물, git 에 포함)
```

### 코드 읽는 순서 추천
1. `src/main.js` 맨 아래 `start()` — 데이터 파일을 읽고 지도를 만드는 시작점
2. `render()` — 상태(`state`)가 바뀌면 목록·상세·마커·핀·경로를 전부 다시 그린다. **모든 화면 변경은 `state` 를 바꾸고 `render()` 를 부르는 방식**입니다.
3. `src/map.js` 의 맨 위 주석 — 지도에 무엇을 그릴 수 있는지(함수 목록)

| 기능 | 데이터 | 비고 |
|---|---|---|
| 건물별 가격표 마커, 층별 실거래가 | 국토교통부 전월세 실거래가 (연립다세대·오피스텔), 최근 12개월 | 같은 지번 = 같은 건물로 묶음 |
| 필터 (보증금·월세·유형·계약종류·면적·통학 목적지·도보시간·정렬) | 위 + travel-times.json | |
| 주요 목적지 28곳까지 도보·자전거 시간 | OSRM (`routing.openstreetmap.de`) | 미리 계산 |
| 경로선 + 오르막·내리막 색 | OSRM 경로 + Open-Meteo 고도 | 누를 때 실시간 요청 |
| 편의시설 (편의점·빨래방·세탁소·마트·약국) | 카카오 장소 검색 + OSRM 도보거리 | 미리 계산 |
| 로드뷰 | 카카오맵 SDK | 카카오맵일 때만 |
| 매물 사이트 링크 | 다방·네이버부동산·직방 (링크만) | 공개 API 없음 → 매물 자체는 가져오지 않음 |
| LH 임대공고 | LH 분양임대공고문 조회 서비스 (서울) | 모집 중 + 최근 6개월 마감 |

## 6. 알려진 한계와 주의점

- **지도의 가격은 끝난 계약 기록**입니다. 지금 나와 있는 매물이 아닙니다. 직방·다방·네이버부동산은 공개 API 가 없어서 링크로만 연결합니다. 이 사이트들을 긁어 오는 것은 이용약관 위반 소지가 있어 하지 않았습니다.
- **단독·다가구는 빠져 있습니다.** 이 자료는 층·건물명이 없고 지번이 일부 가려져 있어 건물 단위로 찍을 수 없습니다. 동네 단위 시세로 보여 주는 방식을 검토 중이었습니다.
- **좌표는 지번 기준**이라 건물 정문과 수십 m 어긋날 수 있습니다.
- **소요시간은 예상값**입니다. 언덕·신호 대기가 반영되지 않습니다. 오르막·내리막은 고도 격자가 성겨서 대략적인 값입니다.
- **경로선은 공개 서버에 실시간으로 요청**합니다. 서버가 막히면 선이 안 그려집니다(표의 시간은 미리 계산한 파일이라 그대로 보임).
- **네이버부동산 링크**는 좌표로 열리는 형식으로 넣었지만, 개발 환경에서 직접 열어 확인하지는 못했습니다. **직방 링크**는 좌표를 무시해서 원룸 지도만 열립니다.
- 같은 날·같은 층·같은 가격 거래가 두 줄로 보이는 경우가 있는데, 국토부 자료에 그렇게 들어 있는 것입니다.
- `vite build` 로 배포용 파일을 만들 수 있지만, 실제 배포는 해 보지 않았습니다. 배포 시 카카오 도메인 등록이 필요합니다.

## 7. 아직 만들지 않은 기능 (요청 받은 것)

| 기능 | 필요한 것 |
|---|---|
| AI 챗봇 ("15분 내로 생활과학대학 갈 수 있는 자취방 알려줘") | AI API 키 + 키를 숨길 서버(서버리스 함수 등). `travel-times.json`·`deals.json` 을 그대로 검색 근거로 쓸 수 있음 |
| 경희대 계정 로그인, 기록 저장, 댓글 | 인증·DB 서버 (예: Firebase/Supabase + 구글 로그인을 `@khu.ac.kr` 로 제한) |
| 후기 남기기 | 위와 같은 서버 |
| 단독·다가구 시세 | 6장 참고 |
| 혼잡도 | 쓸 만한 공개 자료를 찾지 못함 |
